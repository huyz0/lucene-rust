# lucene-highlighter -- the classic Highlighter (M13 T13.2)

[Index](../parity.md). `org.apache.lucene.search.highlight`: a token stream cut into
fragments, tokens scored by the query, matching tokens marked up. The unified highlighter's
subset is in [search-collectors.md](search-collectors.md); T13.2 ports the rest of the module in
slices (classic first).
