# lucene-sandbox (M14.f)

[Index](../parity.md). `org.apache.lucene.sandbox`: experimental fields, queries, codecs and
facets. `FuzzyLikeThisQuery` (ported for M13's XML parser) is in [queries.md](queries.md); the
class-by-class triage is `docs/inventory/lucene-sandbox.tsv`. Unit tests without a Java
counterpart: `lucene-codecs/src/idversion/tests.rs`, `lucene-codecs/src/quantization/tests.rs`.
