# lucene-sandbox (M14.f)

[Index](../parity.md). `org.apache.lucene.sandbox`: experimental fields, queries, codecs and
facets. `FuzzyLikeThisQuery` (ported for M13's XML parser) is in [queries.md](queries.md); the
class-by-class triage is `docs/inventory/lucene-sandbox.tsv`.

| `sandbox/search/SortedNumericDocValuesMultiRangeQuery` | `lucene-search/src/sandbox/search/doc_values_multi_range.rs::SortedNumericDocValuesMultiRangeQuery` | **ported** M14.f: `resolveOverlaps` through Lucene's `PriorityQueue` (points first on ties, reversed ranges dropped by the sign of a wrapping `lower - upper`), the floor lookup per value with `rangeTree.tailSet`'s cut, the skipper's segment rule-out. With a skip index it walks `SkipBlockRangeIterator`'s blocks and reproduces `matches()` reading a stale iterator (a candidate before the document `values` sits on reads that document's count of values, carrying on from where the last call stopped): Java returns extra documents there, and so does this port. Equal to Lucene's over sorted-numeric and numeric fields, skip-indexed multi- and single-valued, and a 9,000-document segment with deletions (`search(q, 10)`'s total hits, `count(q)`, every hit) -- `sandbox_document_fixtures.rs`. Differs: every range reversed is an error (Java: `NoSuchElementException`); a stale read past the field's last value ends the match (Java reads past the column: an `EOFException`, or a value decoded from `DirectWriter`'s padding that may match). Bench: `sb_dv_multi_range` 1.45x, `sb_dv_multi_range_skip` 2.66x (a dense field reads no stale values, so a skip block whose values miss every range is passed over, its candidates seen only by the window bookkeeping; the faithful port, confirming every candidate, measured below 1.0x on this case; the sparse stale-read path is not benchmarked). |
