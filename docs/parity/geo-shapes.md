# lucene-index / lucene-search -- geo shapes (M9 T9.3)

[Index](../parity.md). The shape half of Lucene's geo `document` classes:
`ShapeField`'s triangle encoding, `LatLonShape`/`XYShape` fields and doc values,
every shape query. Tests (`GenGeoShapes` -> `geo_shapes_fixtures.rs`, 1,576
queries over Lucene's index and this port's; `VerifyGeoShapes`) and the
benchmark (`--bench geo_shapes`, 1.09x-1.76x):
[M9 evidence](../milestones/m9-geo-and-spatial.md#ledger-evidence).
