# lucene-index

[Index](../parity.md). `org.apache.lucene.index` write side and
`org.apache.lucene.document` (fields, encodings) as they live in
`lucene-index`: segment/commit files, `IndexWriter` and its flush, merge,
delete and deletion-policy machinery, NRT snapshots. Readers and `CheckIndex`:
[search-readers.md](search-readers.md); block joins: [joins.md](joins.md); geo
fields: [geo-points.md](geo-points.md), [geo-shapes.md](geo-shapes.md); the
engine's writer features: [engine.md](engine.md).
