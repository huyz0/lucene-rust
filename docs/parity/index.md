[Index](../parity.md). `org.apache.lucene.index` write side and
`org.apache.lucene.document` (fields, encodings) in
`lucene-index`: segment/commit files, `IndexWriter` flush, merge,
delete, deletion policies, NRT snapshots. Readers, `CheckIndex`:
[search-readers.md](search-readers.md); block joins: [joins.md](joins.md); geo
fields: [geo-points.md](geo-points.md), [geo-shapes.md](geo-shapes.md);
engine writer features: [engine.md](engine.md).
