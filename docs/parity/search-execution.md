[Index](../parity.md). How queries are scored and run: the scorer tree (`exec/`), bulk scorers,
similarities, multi-segment fan-out. The query types themselves:
[search-queries.md](search-queries.md); collectors, sorting, facets and
aggregations: [search-collectors.md](search-collectors.md).
