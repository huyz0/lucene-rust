# lucene-analysis

[Index](../parity.md). Lucene core's `analysis` package (streaming model,
`StandardTokenizer`) and the analysis-common filters ported ahead of M11.
Offsets everywhere are Java `char` (UTF-16) offsets; the `utf16_*` cases of
`fixtures/src/GenAnalysis.java` pin them behind supplementary-plane text.
Main differential test: `crates/lucene-analysis/tests/analysis_fixtures.rs`.
