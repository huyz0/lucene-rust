# lucene-analysis

[Index](../parity.md). Lucene core's `analysis` package (streaming model,
`StandardTokenizer`), analysis-common filters ported ahead of M11.
Offsets are Java `char` (UTF-16) offsets; `utf16_*` cases of
`fixtures/src/GenAnalysis.java` pin them past supplementary-plane text.
Main differential test: `crates/lucene-analysis/tests/analysis_fixtures.rs`.
