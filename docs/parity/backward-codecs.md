# lucene-codecs -- backward codecs (M8)

[Index](../parity.md). Reading (and merging away) every format Lucene 9.0-10.4
wrote; Lucene 8 formats are rejected. Per-class status:
`docs/inventory/lucene-backward-codecs.tsv`. Tests: `bwc_fixtures.rs` over
`fixtures/data/bwc/<version>/` (one index per codec era, every line of
10.5.0's `expected.txt`, 34 queries per version, `CheckIndex`);
`scripts/verify-bwc-merge.sh` ([M8 evidence](../milestones/m8-backward-codecs.md#ledger-evidence)).
