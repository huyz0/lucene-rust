# knn_vector -- the k-NN plugin's vector field and knn query

[Index](../parity.md). Not a Lucene module: OpenSearch's k-NN plugin
(3.9.0.0) owns `knn_vector` and `knn`; the lucene-rust plugin serves both
itself, on Lucene's vector formats, searched in Rust. Plan and stages:
`/mnt/project-files/plan/knn-vector-native.md` in the project notes.

| Java | Rust | Status |
|---|---|---|
| -- (k-NN `KNNVectorFieldMapper`, `KNNMethodContext`, `EngineResolver`, `ModeBasedResolver`, `KNNSettings`) | `opensearch-plugin/.../knn/{KnnVectorFieldMapper, KnnFieldConfig, SpaceType, KnnSettings, KnnVectors}.java`, `opensearch-plugin/.../engine/VectorsFormatSpec.java`; `lucene-ffi/src/engine_writer.rs::{decode_vector_schema, parse_vectors_format, restore_vectors_formats, VECTORS_FORMAT_ATTRIBUTE}`, `lucene-index/src/concurrent_writer.rs::add_explicit_documents_with_vectors_in` | **rust-only** (port of k-NN, mapping side). dimension, data_type float/byte, space_type l2/cosinesimil/innerproduct, hnsw on the lucene engine (m, ef_construction; a mapping without an engine resolves to lucene and persists it, `engine: faiss` is refused), lucene sq encoder bits 7/4/2/1, mode and compression_level, doc_values, store; the field's format (Lucene99 HNSW or Lucene104 HNSW scalar quantized) travels as `lucene_rust.knn_format`.
