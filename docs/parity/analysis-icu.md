# M12 analysis-icu

[Index](../parity.md). `lucene-analysis-icu` (M12 T12.4) over a port of the ICU4J 77.1 runtime it calls (`src/icu4j/`), reading ICU's own data files (`src/resources/`; the collation bundles packed by `tools/GenIcuCollPack.java`); per-class status is `docs/inventory/lucene-analysis-icu.tsv`. Why ICU4J's code and not ICU4X: [`lib.rs`](../../crates/lucene-analysis-icu/src/lib.rs) and [licences](../licences.md). ICU4J classes have `--` in the Java column and are named in the status.
