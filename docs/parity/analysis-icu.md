[Index](../parity.md). `lucene-analysis-icu` (M12 T12.4) over port of the ICU4J 77.1 runtime it calls (`src/icu4j/`), reading ICU's own data files (`src/resources/`; collation bundles packed by `tools/GenIcuCollPack.java`); per-class status is `docs/inventory/lucene-analysis-icu.tsv`.
