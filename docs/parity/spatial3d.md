# lucene-util / lucene-index / lucene-search -- spatial3d (M9 T9.4)

[Index](../parity.md). `lucene-spatial3d`'s `geom` package in `lucene-util`,
plus `Geo3DPoint` and its query/sorts. No index format of its own, but the
indexed x/y/z and per-cell relationships come from it, so everything is held to
Java's bits. The port uses fdlibm trigonometry; the generators run with
HotSpot's sin/cos/tan intrinsics disabled. Tests (`GenGeo3d`, `GenGeo3dMath`)
and benchmarks (`--bench geo3d` 1.01x-1.41x, `--bench geo3d_points`
1.18x-1.74x): [M9 evidence](../milestones/m9-geo-and-spatial.md#ledger-evidence).
