# lucene-classification -- text classifiers (M14 T14.3)

[Index](../parity.md). `org.apache.lucene.classification`: classifiers that learn from an index's
documents by searching it -- naive Bayes, k nearest neighbours, a boolean perceptron -- their
whole-document flavours, and the tools that evaluate them and split an index into training,
test and cross-validation sets. Java's classifiers take an `IndexReader`; here a `TrainingIndex`
carries the reader, its opened segments, norms and the JVM's `BytesRef` hash seed (equal scores
come out in `HashMap` order, which follows it).
