# lucene-ffi -- the OpenSearch plugin boundary (M2, M5.6)

[Index](../parity.md). Pinned OpenSearch: **3.9.0** (`lucene_version`
10.5.1). Plugin: `opensearch-plugin/`; what runs native and
why the rest falls back: [`docs/accelerated-queries.md`](../accelerated-queries.md).
Engine (write side): [engine.md](engine.md); geo queries:
[plugin-geo.md](plugin-geo.md). Plugin-facing search features
(sorts, aggregations, `terminate_after`, fetch): the `search-*.md` files.
