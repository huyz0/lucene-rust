# lucene-util / lucene-search -- spatial-extras (M9 T9.5)

[Index](../parity.md). **Ported**: every class of the jar
(`docs/inventory/lucene-spatial-extras.tsv`), on ports of the subsets of
Spatial4j 0.8 and s2-geometry-library-java 1.0.0 it exercises (`lucene-util`;
`docs/licences.md`). JTS is not ported: polygons go through Geo3D; a non-Geo3D
context answers a POLYGON with Spatial4j's `UnsupportedOperationException`.
Tests (`GenSpatial4j`, `GenSpatialPrefixTree`, `GenSpatialStrategies`,
`VerifySpatialExtras`) and the benchmark (`--bench spatial_extras`, 1.01x-1.38x):
[M9 evidence](../milestones/m9-geo-and-spatial.md#ledger-evidence).
