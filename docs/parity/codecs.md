# lucene-codecs

[Index](../parity.md). The 10.5.0 default codec's formats (`Lucene104` postings,
`Lucene103` block tree, `Lucene90` stored fields/doc values/norms/points/term
vectors/compound/live docs, `Lucene94` field infos, `Lucene99` vectors) and the
`util` encoders they are built on (`packed`, `fst`, `compress`, automaton
intersection). Formats Lucene 9.x wrote: [backward-codecs.md](backward-codecs.md).
