# lucene-expressions -- JavaScript expressions (M14 T14.2)

[Index](../parity.md). `org.apache.lucene.expressions`: an expression over named variables,
compiled once, evaluated per document as a `DoubleValuesSource`. Java parses with an ANTLR
grammar and compiles to a hidden JVM class (ASM); the Rust port parses by hand against the same
grammar and compiles the tree to closures that keep the JVM's typing.

Bench (`bench-micro.sh expressions`, ns Java/Rust): compile 22,470 vs 3,003; per document arith 2.5 vs 10.7, math 12.6 vs 36, cond 5.3 vs 15.8, bits 4.0 vs 16.3, haversin 29.2 vs 34, funcs 7.3 vs 21. Left slower: the JIT inlines Java's generated bytecode, variable reads included; Rust has no runtime codegen, and the reads alone (`dyn` calls) are 5.7 of arith's 10.7 ns. |
