# lucene-suggest -- suggesters and completion postings format (M13 T13.3)

[Index](../parity.md). `org.apache.lucene.search.suggest`: `Lookup` API every suggester
implements, `InputIterator` family it is built from, FST and TST lookups, analyzing
suggesters, and `suggest.document`'s completion postings format that OpenSearch uses. T13.3 is
planned as sub-tasks: (a) base layer, (b) TST and FST lookups, (c) analyzing
suggesters, (d) `suggest.document`, (e) spell. T13.3a: base layer.
