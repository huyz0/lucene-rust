# lucene-test-framework (M14.h)

[Index](../parity.md). `org.apache.lucene.tests`: the randomized test framework, ported as the
`lucene-test-framework` crate -- a dev-dependency only, never linked into `lucene-ffi`. The
class-by-class triage is `docs/inventory/lucene-test-framework.tsv`; JUnit runner machinery
(rules, listeners, thread filters) is not-needed there, since `cargo test` runs the tests.
Generators: `fixtures/src/testframework/` via `scripts/gen-test-framework-fixtures.sh`. No
bench pairs: test-only code.
