# M12 analysis-opennlp

[Index](../parity.md). `lucene-analysis-opennlp` (M12 T12.5) over a port of the Apache OpenNLP 2.5.3 inference runtime it calls (`src/tools/`, one module per OpenNLP package), reading OpenNLP's own model packages; per-class status is `docs/inventory/lucene-analysis-opennlp.tsv`. Why a port and not a JVM call: [`lib.rs`](../../crates/lucene-analysis-opennlp/src/lib.rs). Evidence: `fixtures/src/GenAnalysisOpenNLP.java` trains ten small models with OpenNLP itself (seeded synthetic grammar) and writes `analysis_opennlp/` -- 2,500+ `NLP*Op` rows (`tools.tsv`), 54 token classes, 14 feature-generator rows and 23 `CustomAnalyzer` chains (8 refused), byte-identical under JDK 21 and 25 -- checked by `tests/opennlp_fixtures.rs`; `tests/opennlp_hostile.rs` covers what Java refuses.
