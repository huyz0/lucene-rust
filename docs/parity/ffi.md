# lucene-ffi -- the general C ABI

[Index](../parity.md). The C-ABI surface over `lucene-search`/`lucene-index`
that predates the OpenSearch plugin. **The plugin calls none of it**: its
downcalls are `lucene-ffi/src/jvm_reader.rs`, `jvm_aggs.rs`, `jvm_fetch.rs`,
`engine_writer.rs` and `ffm_bridge.rs` ([plugin.md](plugin.md),
[engine.md](engine.md)). Every function here is a thin wrapper: no search,
sort, facet or highlight logic is reimplemented, and each is tested against a
direct call of the function it wraps on real Java-written fixtures, plus its
null/handle/UTF-8/length error paths (per-file `#[cfg(test)]` modules).
Conventions: opaque `u64` handles, `catch_unwind` around every body
(`guard`), registry mutexes taken with `lock_recovering`, caller-allocated
out-buffers (`buf`/`buf_len`/`out_written`/`BufferTooSmall`).
