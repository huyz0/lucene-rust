# lucene-tools -- the command-line tools (M14.i)

[Index](../parity.md). The `main` methods of `lucene-misc`, `lucene-demo`, `lucene-luke`
and `lucene-benchmark`, each under its Java class name behind one `lucene-tools` binary
(`lucene-tools <Tool> [args...]`). Every tool writes to an injected `System.out`/`System.err`
and returns `System.exit`'s code, so it is tested in-process against what the Java tool
printed. An exception out of a tool prints the JVM's `Exception in thread "main" ...` line
without the stack trace, and exits 1; the message is Java's where the tool composes it
(argument checks, `RuntimeException`s), the library's otherwise (I/O, a missing index). No
bench pair: these are command lines, not hot paths -- each is one library call the library's
own rows benchmark.
