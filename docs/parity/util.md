# lucene-util

[Index](../parity.md). `org.apache.lucene.util` (and two JDK classes) ported
into `lucene-util`, plus the few `util` classes that need a `Directory` and so
live in `lucene-codecs`. Geo and spatial3d math: [util-geo.md](util-geo.md),
[spatial3d.md](spatial3d.md).
