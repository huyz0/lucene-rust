# lucene-codecs (M14.g)

[Index](../parity.md). `org.apache.lucene.codecs.*` in the `lucene-codecs` jar: the non-default
postings formats and codecs. The default codec's formats are in [codecs.md](codecs.md); the
class-by-class triage is `docs/inventory/lucene-codecs.tsv`. These formats are module-level readers
and writers over a group's files, like sandbox's `IDVersion` ([sandbox.md](sandbox.md)): this
port's `IndexWriter` routes no field to them and `DirectoryReader` does not open them. Unit tests
without a Java counterpart: `lucene-codecs/src/bloom/tests.rs`, `lucene-codecs/src/memory/tests.rs`,
`lucene-codecs/src/bitvectors/tests.rs`, `lucene-codecs/src/blocktreeords/tests.rs`.
