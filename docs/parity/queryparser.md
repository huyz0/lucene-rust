# lucene-queryparser (M13 T13.1)

Query strings into queries. The classes are Lucene 10.5.0's
`lucene-queryparser` module; the Rust lives in `lucene-search`'s
`queryparser` module. What of the module is still owed is
`docs/inventory/lucene-queryparser.tsv` (`scripts/check-port-inventory.py
--module queryparser --milestone M13 --summary`).
